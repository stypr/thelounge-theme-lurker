### [The Lounge](https://thelounge.chat/)

#### Install using thelounge

    thelounge install thelounge-theme-lurker

#### Install using Git

If you are a git user, you can install the theme and keep up to date by cloning the repo:

    git clone https://github.com/stypr/thelounge-theme-lurker.git

#### Install manually

Download using the [GitHub .zip download](https://github.com/stypr/thelounge-theme-lurker/archive/master.zip) option and unzip them.

#### Activating theme

1. Copy dracula.css to ~/thelounge/public/themes/
2. Restart thelounge
3. Happy chatting!
